**Интерактивная книжная выставка, посвящённая 60-летию Краснодарского государственного института культуры (КГИК).**

[Перейти на сайт выставки](https://chuxlee.github.io/golden-shelf/)

## О проекте

Golden Shelf — цифровая выставка, объединяющая материалы о научной, педагогической и творческой деятельности преподавателей Краснодарского государственного института культуры.

Проект направлен на сохранение и популяризацию научного и культурного наследия института, систематизацию библиографических материалов и обеспечение свободного доступа к истории КГИК через труды и достижения его преподавателей.

В экспозиции представлены биографии педагогов, научные публикации, монографии, учебные пособия, художественные альбомы, нотные издания, фотографии, аудио- и видеоматериалы.

Выставка предназначена для студентов, преподавателей, выпускников, исследователей и всех, кто интересуется историей института, наукой, образованием и культурой.

## Функциональные возможности

- Электронный каталог преподавателей КГИК.
- Отдельный раздел, посвящённый ректорам института.
- Персональные страницы преподавателей с биографиями.
- Каталог научных, учебных и творческих трудов.
- Страницы изданий с обложками, библиографическими описаниями и аннотациями.
- Полные библиографические списки публикаций.
- Поиск по именам преподавателей, названиям книг и публикаций.
- Фильтрация преподавателей по учёной степени, учёному званию и отрасли наук.
- Поддержка фотографий, аудиозаписей, видеоматериалов, PDF-документов и внешних ссылок.
- Автоматизированный импорт данных из Яндекс Форм.

## Локальный запуск

### Системные требования

Для локальной работы с проектом необходимо установить:

- Git;
- Ruby;
- RubyGems;
- Bundler;
- Python 3.10 или новее — для использования скрипта импорта.

### 1. Клонирование репозитория

```bash
git clone https://github.com/chuxlee/golden-shelf.git
cd golden-shelf
```

### 2. Установка зависимостей

При необходимости установите Bundler:

```bash
gem install bundler
```

Установите зависимости проекта:

```bash
bundle install
```

### 3. Запуск сайта

```bash
bundle exec jekyll serve
```

После успешного запуска сайт будет доступен по адресу:

http://localhost:4000/golden-shelf/

Для запуска с автоматическим обновлением страницы при изменении файлов:

```bash
bundle exec jekyll serve --livereload
```

### 4. Сборка сайта

```bash
bundle exec jekyll build
```

Сгенерированные файлы сайта будут размещены в каталоге `_site/`.

При возникновении проблем со сборкой можно использовать расширенный вывод ошибок:

```bash
bundle exec jekyll serve --trace
```

## Работа с контентом

Контент сайта отделён от шаблонов и хранится в Markdown-файлах с YAML Front Matter.

Такой подход позволяет добавлять преподавателей и издания без необходимости изменять HTML-код страниц.

### Добавление преподавателя

Создайте файл в каталоге `_persons/`.

Название файла должно содержать уникальный идентификатор преподавателя, записанный латинскими буквами.

Например:

```text
_persons/ivanov.md
```

Пример содержимого:

```markdown
---
title: "Иванов Иван Иванович"
name: "Иванов Иван Иванович"
author_id: ivanov

degree: "Доктор наук"
academic_title: "Профессор"
science_field: "Педагогические науки"

years_at_kgik: "1995–2025"

photo: "/assets/images/persons/ivanov/portrait.jpg"

bio_short: "Краткая информация о преподавателе."

bibliography:
  - "Библиографическое описание первой публикации."
  - "Библиографическое описание второй публикации."
---

## Биография

Полная биография преподавателя.

## Научная деятельность

Информация о научной деятельности.

## Награды и достижения

Информация о профессиональных достижениях.
```

### Поля преподавателя

| Поле | Описание |
|---|---|
| `title` | Заголовок страницы |
| `name` | Фамилия, имя и отчество |
| `author_id` | Уникальный идентификатор преподавателя |
| `degree` | Учёная степень |
| `academic_title` | Учёное звание |
| `science_field` | Отрасль наук |
| `years_at_kgik` | Годы работы в институте |
| `photo` | Путь к портрету |
| `bio_short` | Краткая биографическая справка |
| `bibliography` | Список библиографических записей |
| `media` | Дополнительные мультимедийные материалы |
| `is_rector` | Принадлежность к разделу ректоров |
| `rector_order` | Порядок отображения ректора |
| `rector_years` | Период работы в должности ректора |
| `rector_role` | Название руководящей должности |

Поля, для которых отсутствует информация, можно не указывать.

### Добавление ректора

Для отображения преподавателя в отдельном разделе ректоров необходимо добавить в его YAML Front Matter следующие поля:

```yaml
is_rector: true
rector_order: 1
rector_years: "1995–2005"
rector_role: "Ректор"
```

Ректоры отображаются на главной странице перед основным каталогом преподавателей и сортируются по полю `rector_order`.

### Добавление книги или другого издания

Создайте Markdown-файл в каталоге `_works/`.

Например:

```text
_works/ivanov1.md
```

Пример содержимого:

```markdown
---
title: "Название издания"
author_id: ivanov

cover: "/assets/images/persons/ivanov/book1.jpg"

description: "Краткое описание издания."
---

## Библиографическое описание

Полное библиографическое описание издания.

## Аннотация

Аннотация издания.
```

Связь между преподавателем и его трудами устанавливается автоматически через поле `author_id`.

Значение этого поля в файле преподавателя и файлах его трудов должно совпадать.

## Работа с мультимедиа

Для каждого преподавателя рекомендуется создавать отдельную папку в каталоге `assets/images/persons/`.

```text
assets/images/persons/ivanov/
├── portrait.jpg
├── book1.jpg
├── book2.jpg
├── picture1.jpg
└── picture2.jpg
```

Дополнительные материалы подключаются через поле `media` в файле преподавателя.

```yaml
media:
  - type: "image"
    url: "/assets/images/persons/ivanov/picture1.jpg"
    label: "Фотография из архива"

  - type: "audio"
    url: "/assets/audio/ivanov.mp3"
    label: "Аудиозапись выступления"

  - type: "video"
    url: "https://example.com/embed/video"
    label: "Видеозапись выступления"

  - type: "pdf"
    url: "/assets/images/persons/ivanov/document.pdf"
    label: "Дополнительные материалы"

  - type: "link"
    url: "https://example.com"
    label: "Интервью с преподавателем"
```

### Поддерживаемые типы материалов

| Тип | Назначение |
|---|---|
| `image` | Изображения и фотографии |
| `audio` | Аудиозаписи |
| `video` | Встраиваемые видеоматериалы |
| `pdf` | PDF-документы |
| `link` | Внешние интернет-ресурсы |

Для видеоматериалов необходимо использовать ссылки, поддерживающие встраивание через `iframe`.

## Автоматизированное добавление данных

Для упрощения наполнения выставки предусмотрен скрипт `scripts/import_form.py`, предназначенный для обработки JSON-файлов, экспортированных из Яндекс Форм.

Скрипт позволяет:

- считывать ответы из формы;
- извлекать информацию о преподавателях;
- формировать Markdown-файлы биографий;
- формировать отдельные файлы изданий;
- сопоставлять названия книг, библиографические описания и аннотации;
- создавать каталоги для изображений;
- обрабатывать поддерживаемые вложения;
- проверять корректность входных данных;
- предотвращать перезапись отличающихся существующих файлов.

Для работы скрипта используется стандартная библиотека Python. Установка дополнительных Python-пакетов не требуется.

### Проверка данных без записи файлов

```bash
python scripts/import_form.py "answers.json" --dry-run
```

### Импорт данных

```bash
python scripts/import_form.py "answers.json"
```

### Импорт с локальными вложениями

```bash
python scripts/import_form.py "answers.json" --attachments ./attachments
```

### Импорт со скачиванием вложений

```bash
python scripts/import_form.py "answers.json" --download
```

### Дополнительные параметры

| Параметр | Назначение |
|---|---|
| `--dry-run` | Проверка импорта без записи файлов |
| `--attachments` | Путь к локальной папке с вложениями |
| `--download` | Скачивание недостающих вложений |
| `--site` | Путь к корневому каталогу сайта |
| `--rector` | Указание идентификатора ректора |

Получить полный список параметров можно командой:

```bash
python scripts/import_form.py --help
```

После автоматического импорта рекомендуется проверить оформление биографий, библиографических записей, аннотаций, изображений и мультимедийных материалов.

## Принцип работы сайта

1. Информация о преподавателях хранится в коллекции `_persons`.
2. Информация об изданиях хранится в коллекции `_works`.
3. Jekyll считывает Markdown-файлы и их YAML-метаданные.
4. Liquid формирует страницы на основе HTML-шаблонов.
5. Труды автоматически связываются с преподавателями через `author_id`.
6. JavaScript обеспечивает поиск, фильтрацию и взаимодействие с элементами интерфейса.
7. Сгенерированный статический сайт публикуется на GitHub Pages.
