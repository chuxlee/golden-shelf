## Библиографическое описание

«Песни для детей дошкольного возраста» Чернявский, Владимир Андреевич. Песни для детей дошкольного возраста / В. А. Чернявский ; ст. Т. Гондарь. - Краснодар : Эоловые струны, 1999. - 20 с. - Музыка (знаковая ; визуальная) : непосредственная.

## Аннотация

Вокальный сборник для детей 3–6 лет на стихи Т. Гондарь. Мелодии простые, с небольшим диапазоном, опираются на ритмику детской речи. Тексты о знакомых явлениях. Есть фортепианное сопровождение. Для музыкальных руководителей и родителей.
